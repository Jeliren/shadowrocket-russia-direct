# Shadowrocket Russia Direct

Минимальный профиль Shadowrocket для режима «VPN всегда включён»:

- российские государственные сервисы, банки, маркетплейсы, розница,
  транспорт, медицина и другие сервисы, чувствительные к VPN/IP дата-центров,
  идут `DIRECT` через обычное подключение телефона;
- Reddit идёт `DIRECT` как подтверждённое персональное исключение;
- весь остальной трафик идёт через выбранный в Shadowrocket узел (`PROXY`).

В профиле нет VPN-пароля, прокси-сервера, скриптов, HTTPS MITM, блокировки
рекламы или URL rewrite.

## Установка

В Shadowrocket откройте `Config` → `+` → `Download from URL` и вставьте:

```text
https://raw.githubusercontent.com/Jeliren/shadowrocket-russia-direct/main/profile.conf
```

Выберите скачанный профиль галочкой. На главном экране оставьте выбранным свой
обычный VPN-узел и используйте режим маршрутизации `Config`.

Для фонового получения обновлений включите Shadowrocket → Settings → Auto
Background Update и системный iOS Background App Refresh. iOS не гарантирует
точный момент фонового запуска; после принудительного закрытия приложения
обновление может дождаться следующего запуска Shadowrocket.

## Как обновляются правила

`profile.conf` ссылается на два удалённых RULE-SET:

- `direct-custom.list` — ручные срочные исключения;
- `direct-curated.list` — автоматически собираемый публичный набор.

GitHub Actions ежедневно пересобирает агрегат из выбранных категорий
`v2fly/domain-list-community` и
`haritos90/allow-domains/Russia/russia-outside-surge.list`. Точный перечень
категорий находится в `sources.json`.

## Добавление проблемного сайта

Добавьте `DOMAIN-SUFFIX,example.com` в `direct-custom.list` и отправьте
изменение в ветку `main`. Клиенты получат правило при очередном обновлении
конфигурации/удалённых ресурсов; повторный импорт не требуется.

Перед добавлением нужно подтвердить, что сервис работает с обычного соединения
телефона и не работает через VPN. Не добавляйте широкие правила вроде всей зоны
`.ru`: среди российских доменов есть ресурсы, которым, наоборот, требуется
прокси.

## Источники и лицензии

Сборка использует MIT-лицензированные данные:

- [v2fly/domain-list-community](https://github.com/v2fly/domain-list-community);
- [haritos90/allow-domains](https://github.com/haritos90/allow-domains).

Атрибуция находится в `THIRD_PARTY_NOTICES.md`. Готовые сторонние конфиги
целиком не подключаются.
